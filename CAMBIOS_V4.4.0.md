# RootMine v4.4.0 — Análisis vivo y navegación dinámica

- Las ediciones humanas son la fuente de verdad para GearBot.
- Ishikawa, 5 Porqués y planes editados alimentan la redacción final.
- Si cambia una etapa anterior, el informe queda marcado como desactualizado.
- Botón para actualizar el informe con IA usando el último análisis validado.
- La IA no sobrescribe silenciosamente: la actualización del informe requiere acción explícita.
- Selector de navegación directa entre etapas ya alcanzadas.
- Volver a una etapa conserva el mismo ADF y el trabajo posterior.
- Indicadores de etapas modificadas / que requieren actualización.
- Mantiene identidad visual v4.3, planes obligatorios, sesión persistente, borradores, Supabase y trazabilidad.
