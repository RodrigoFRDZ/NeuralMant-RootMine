# RootMine v4.1.2

- Ingeniero de Mantenimiento vuelve a estar disponible como rol RootMine normal.
- El permiso `Administrador RootMine` sigue siendo independiente del cargo/rol.
- Nueva pestaña `Administrar ADF`, visible solo para administradores.
- La eliminación de un ADF exige escribir su número para confirmar.
- Al eliminar un ADF se eliminan también validaciones y notificaciones asociadas.
- Planes y respaldos almacenados dentro del ADF se eliminan con el registro.
- Compatible con Supabase/PostgreSQL y SQLite local.
